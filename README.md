Название проекта: TravelNotes

Цель:  Помощь пользователю в подготовке к путешествию(поездке) не забыть выполнить необходимые задачи

Основной функционал: - Создание новой заметки
                     - Поиск заметки по ключевому слову
                     - Отмечать выполненную заметку
